How It Works:

  1. TTSContext provides global state for TTS activity
  2. UniversalChat updates TTS state when "Read Aloud" is clicked
  3. Sidebar TTSVisualizer subscribes to TTS state changes
  4. Visualizer animates when AI is speaking (outgoing voice)
  5. Shows "AI Speaking" or "TTS Ready" status text

🧪 Manual Testing Steps

To Test the TTS Visualizer:

  1. Open the frontend application
  2. Look at the bottom of the sidebar (left side)
  3. You should see the TTSVisualizer next to the purple microphone button
  4. Open the Universal Chat (bottom right chat button)
  5. Send a message to the AI
  6. Click the "Read Aloud" button on the AI's response
  7. Watch the sidebar - the TTSVisualizer should animate with moving lines
  8. The status should change from "TTS Ready" to "AI Speaking"
