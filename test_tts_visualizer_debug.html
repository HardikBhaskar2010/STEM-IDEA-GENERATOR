🧪 Testing Steps

To test TTS visualizer response:

  1. Open browser developer console (F12)
  2. Open the frontend application
  3. Look at the sidebar bottom - you should see the visualizer between theme toggle and mic
  4. Open Universal Chat (bottom right)
  5. Send a message: "Hello AI"
  6. Click "Read Aloud" on the AI response
  7. Watch console for TTS debug logs
  8. Watch sidebar visualizer - should animate when AI speaks
